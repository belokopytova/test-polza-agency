## Тестовое задание


#### Установите зависимости из файла requirements.txt:
`pip install -r requirements.txt`

### 1.Проверка доменов

  Файл check_email_domain.py

  Переменная `emails` принимает список email-адресов
  
  Пример:
  
  ```
if __name__ == '__main__':

    emails = [
        'test12@mail.ru',
        'test@rambler.ru',
        'test123@454.45.ru'
    ]
```


### 2.Мини-интеграция с Telegram

  Файл send_message.py
  
  скрипт принимает текст из файла `text.txt` 
  
  **Необходимо установить в файле:**
  
  `TOKEN` - токен телеграм-бота
  
 `CHAT_ID` - ID чата группы, куда будет писать бот
 
 `FILE_PATH` - директория текстового файла text.txt

 Телеграм-бот должен быть добавлен в группу и иметь права писать сообщения
